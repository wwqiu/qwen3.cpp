qwen3.cpp 教程

拆解 LLM 推理黑盒 —— 一份通过不依赖任何第三方代码、一步一步实现 Qwen3 推理引擎的开发教程。

🎯 目标读者

如果你渴望揭开 LLM 底层运行的神秘面纱，对 AI Infra 领域感兴趣却苦于找不到系统的入门门径，或是 C++ 初学者想找一个硬核且充满成就感的极客项目——那这份教程就是为你量身定制的。

✅ 前置要求

  • ✅ C++ 基础：熟悉指针、面向对象（类）、以及基本的 STL 容器。
  • ✅ 一点点线性代数：知道最基本的矩阵乘法和向量运算。
  • ✅ 神经网络常识：对大模型有个概念，听过"权重"、"激活函数"。
  • ⚠️ 完全不需要：任何深度学习框架使用经验、CUDA 编程知识。

📖 你将收获什么

  1. 理解 LLM 推理流程 —— 从文本输入到 token 输出的完整过程
  2. 掌握核心算子实现 —— Embedding、RMSNorm、Attention、MLP 等
  3. 能够独立实现简单的推理引擎 —— 加载模型权重、前向传播、文本生成
  4. 为后续优化打下基础 —— 理解性能瓶颈，知道如何进行优化
